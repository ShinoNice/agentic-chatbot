1º To create a main project folder we do: 
mkdir C:\Users\YourUsername\projects
cd C:\Users\YourUsername\projects

2º If we wish to clone a repo inside the desired folder:
git clone https://etcetctetctetcetc.git

3º To install UV we do:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

4º Build env
uv init

5º Install packages
uv add -r requirements.txt

5º To run the uv env we do:
uv sync

6º To activate the env in powershell:
.venv\Scripts\Activate.ps1


Other Important Commands:
uv self update - to have the latest uv version
uv pip install lib1 lib2 lib3 - to install whatever libs
uv pip install -r requirements.txt - to install packages in the txt file
uv pip list - to list current packages
